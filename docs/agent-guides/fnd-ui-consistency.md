# fnd-ui-consistency

Use this guide when changing web, desktop, extension, mobile, or CLI presentation.

Result order:

1. Final system verdict and final confidence
2. Writing-style assessment and limitation
3. Claims checked
4. Public-web search summary
5. Reviewed source cards
6. Gemini evidence analysis
7. Warnings and limitations

Rules:

- Do not show stack traces, file paths, environment variables, raw provider JSON, request IDs, trace IDs, raw timings, token values, or rejection enums to normal users.
- Do not label ModernBERT output as factual truth.
- Do not label Gemini output as the final verdict.
- Map backend stable error codes to friendly user messages.
- Do not use red/green alone to communicate truth.
