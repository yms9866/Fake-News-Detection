# Fake News Detection Platform Operations

This repository is a modular monolith with ports-and-adapters boundaries:

```text
packages/backend/fnd/domain      core entities, enums, policy inputs
packages/backend/fnd/ports       replaceable provider and persistence contracts
packages/backend/fnd/application workflows and services
packages/backend/fnd/adapters    concrete model, search, Gemini, media, persistence adapters
apps/api                         FastAPI composition root and HTTP routes
apps/web                         browser client
apps/desktop                     Electron client
apps/extension                   Chrome MV3 client
apps/mobile                      Expo/React Native client
apps/cli                         command-line reporting
packages/contracts               Python, TypeScript, and OpenAPI contracts
```

## Environment

Supported persistence selection:

```env
PERSISTENCE_BACKEND=memory
DATABASE_URL=
GEMINI_API_KEY=
```

Use `PERSISTENCE_BACKEND=postgresql` or `PERSISTENCE_BACKEND=mysql` with a matching `DATABASE_URL` only after running migrations and integration tests for that backend.

Docker database profiles:

```powershell

python infra/alembic/run_migrations.py
```

## Evidence Pipeline

The analysis workflow separates:

1. Writing-style assessment
2. Atomic factual claims
3. Broad public-web search
4. Source-page review and qualification
5. Gemini evidence analysis
6. Deterministic final verdict

Important user-facing truths:

- Writing style is not factual truth.
- Gemini is evidence analysis, not the final authority.
- Search snippets discover sources but do not qualify as evidence.
- The system searches broadly across the public web, not the literal whole internet.
- Insufficient evidence is a valid result.

## Auth

The local auth routes live under `apps/api/app/routes/auth.py`:

```text
POST /v1/auth/sign-in
GET  /v1/auth/session
POST /v1/auth/refresh
POST /v1/auth/sign-out
```

Session tokens are generated by the application service and stored as hashes through the token repository port. Clients should keep tokens out of content scripts and never render token values.

## Live OCR

Live OCR endpoints live under `apps/api/app/routes/live.py`. Capture must be explicit and visible to the user. Normal UI should show friendly states such as capturing, paused, ready to verify, and stopped. It should not display raw event sequence numbers, hashes, counters, temporary paths, or adapter internals.

Frames are temporary by design. Persist metadata and stable accumulated text, not raw screenshots by default.
